# Issuer Trust Registry Governance Framework — Two Editions

This folder holds the Track 1 issuer trust registry governance framework in two editions. They say the same thing about the domain — government issuers of identity documents (passport, national ID card, driver's license) — and differ only in how they are packaged.

## Which one to read

- **[Standalone edition](issuer-trust-registry-governance-framework.md)** — self-contained, neutral, no dependency on any other framework or organization. Read this if you want the full framework in one document, or you are evaluating it outside any particular trust network. This is the neutral GDC Task Force artifact.
- **[Ayra-layered edition](ayra-layered-issuer-trust-registry-GF-v0.1.md)** — the same domain expressed as a child governance framework anchored on the [Ayra Trust Network Governance Framework (ATNGF)](https://github.com/ayraforum/ayra-trust-network-GF). It inherits the base and adds only the government-issuer specifics. Read this to see how the domain composes onto the Ayra Trust Network.

## Why two

To show that the domain content is separable from any single home. The standalone edition proves the framework stands on its own. The layered edition proves the same framework anchors cleanly onto a base — inheriting principles, invariants, roles, and the queryable surface rather than restating them. The layered edition is deliberately short; the base carries the weight.

The standalone edition is the single source of truth for the shared domain narrative (sovereignty boundary, authority options, worked examples). The layered edition points to it rather than duplicating, so the two cannot drift.

## A note on roles

In neither edition is Ayra the governing or administering authority of an implementation. That authority is the sovereign, regional, or industry body that holds the underlying power. Ayra's role, in the layered edition, is steward of the ATNGF base and neutral convener of cross-ecosystem recognition — coordinate, not operate.
