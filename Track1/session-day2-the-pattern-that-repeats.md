# The Pattern That Repeats: Trust Registries Across Every Credential Domain

Track 1 — Day 2 session

## Description

A passport, a university degree, a customs declaration, a professional licence — different documents, different authorities, all sharing one unanswered question: *is this issuer recognized to issue this, and is that still true?* No credential format answers it — ISO/IEC 18013-5, SD-JWT, and W3C VC don't do that. Where Track 2 wires the answer to a live mobile driver's licence, this session works one level up: the issuer trust registry as a general governance function that recurs across identity documents, education, professional qualifications, travel, business registration, and trade documents, permits, and licences. A practitioner-level session for a working group that will build the pattern once and reuse it everywhere.
